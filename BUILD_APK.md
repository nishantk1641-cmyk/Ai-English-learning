# Build the APK

This folder is a complete Android Studio project.

1. Open the project in Android Studio.
2. Let Gradle sync/download the Android Gradle Plugin.
3. Choose **Build → Build APK(s)**.
4. The debug APK will be under `app/build/outputs/apk/debug/`.

This environment does not contain the Android SDK/Gradle build tools, so an actual compiled APK cannot be produced here. The source project is ready for Android Studio.
